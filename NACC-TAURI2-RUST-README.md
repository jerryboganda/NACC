# NACC Tauri 2 + Rust Document Package

This package supersedes the earlier Electron/Nimbalyst-oriented NACC draft.

Files:

1. `native-agent-control-center-tauri2-rust-master-plan.md` — governing product, architecture, security, workflow, GUI, provider, and delivery plan.
2. `native-agent-control-center-tauri2-rust-build-prompt.md` — direct execution prompt for Claude Code or another capable coding agent.

Mandatory stack: latest stable Tauri 2 at implementation time, Rust application backend/orchestration core, React + TypeScript GUI, Windows-first.
